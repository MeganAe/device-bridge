Guide de démarrage

Les étapes essentielles pour connecter et piloter un appareil Android.

Connexion USB

  1. Sur Android, activez les Options pour les développeurs puis le Débogage USB.
  2. Branchez le téléphone et acceptez l’empreinte de l’ordinateur sur l’écran Android.
  3. Choisissez Rechercher les appareils si le téléphone n’apparaît pas.

Connexion sans fil

  1. Reliez l’ordinateur et le téléphone au même réseau local.
  2. Dans Options pour les développeurs, ouvrez Débogage sans fil puis choisissez Appairer avec un code.
  3. Recopiez l’adresse d’appairage et le code à six chiffres, puis saisissez l’adresse de débogage après l’appairage.

Affichage et luminosité

Les réglages d’affichage s’ouvrent depuis le bouton de paramètres de l’appareil. Les captures sont enregistrées dans Pictures/Device Bridge.

Fichiers et diagnostics

  • Installer un APK… installe un fichier APK choisi sur l’appareil connecté.
  • Envoyer un fichier… copie le fichier vers le dossier Android Download avec progression.
  • Récupérer un fichier… accepte un chemin Android absolu, par exemple /sdcard/Download/rapport.pdf.
  • Logcat montre les journaux en direct ; le terminal ADB exécute une commande après confirmation. Vérifiez toute commande avant de l’envoyer.
  • Les captures et notifications se configurent dans Paramètres ; l’enregistrement vidéo se règle depuis le bouton de paramètres de l’appareil.
  • La vérification des mises à jour compare la version à la dernière publication GitHub et ouvre sa page sur demande ; rien n’est installé automatiquement.

Dépannage rapide

  • Autorisation requise : déverrouillez le téléphone et acceptez la demande de débogage USB.
  • Installateur bloqué sur AdbWinApi.dll : quittez Device Bridge, puis fermez ses processus ADB avant de réessayer.
  • Fenêtre noire : vérifiez que Microsoft Edge WebView2 Runtime est installé, puis relancez l’application.
